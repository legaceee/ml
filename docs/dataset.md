# Dataset Documentation: CIC-IDS2017 Benchmark

## 1. Overview
The **CIC-IDS2017** dataset is generated by the Canadian Institute for Cybersecurity (UNB) using the B-Profile system to simulate realistic user behavior and inject common modern attack patterns over an active 5-day capture window (Monday 8:30 AM to Friday 5:00 PM).

### Captures by Day:
- **Monday**: 100% Benign background activity (baseline user flows).
- **Tuesday**: Brute Force attacks (FTP-Patator, SSH-Patator).
- **Wednesday**: DoS (Hulk, GoldenEye, slowloris, Slowhttptest) and Heartbleed.
- **Thursday**: Web Attacks (Brute Force, XSS, SQL Injection) and Infiltration.
- **Friday**: Botnet (ARES), PortScan, and DDoS (LOIC).

---

## 2. Feature Extractor: CICFlowMeter
Traffic captures were processed using CICFlowMeter into tabular bidirectional flows defined by the 5-tuple:
$(\text{Source IP}, \text{Source Port}, \text{Dest IP}, \text{Dest Port}, \text{Protocol})$.

Calculated statistics include:
- **Volumetric throughput**: `Flow Bytes/s`, `Flow Packets/s`
- **Inter-arrival times**: `Flow IAT Mean/Std/Max/Min`, `Fwd IAT`, `Bwd IAT`
- **Packet Lengths**: `Packet Length Mean/Std/Variance`, `Fwd Packet Length Max`
- **TCP Connection Signaling**: `SYN Flag Count`, `ACK Flag Count`, `FIN Flag Count`, `RST Flag Count`
- **Window Dynamics**: `Init_Win_bytes_forward`, `Init_Win_bytes_backward`, `min_seg_size_forward`
