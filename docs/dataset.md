# Dataset: CIC-IDS2017

## 1. Origin

Generated by the Canadian Institute for Cybersecurity (University of New Brunswick) in July 2017 (Sharafaldin, Habibi Lashkari & Ghorbani, *Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization*, ICISSP 2018). A B-Profile system replayed realistic user behaviour for 25 users over 5 days while real attack tools were run against the victim network. Packet captures were converted to bidirectional **flows** with CICFlowMeter.

| Day | Traffic |
|:--|:--|
| Monday | benign only |
| Tuesday | FTP-Patator, SSH-Patator (brute force) |
| Wednesday | DoS Hulk, GoldenEye, slowloris, Slowhttptest; Heartbleed |
| Thursday | Web brute force, XSS, SQL injection; Infiltration |
| Friday | Bot (ARES); PortScan; DDoS (LOIC) |

Full corpus: **2,830,743 flows, 78 features + label, 15 classes** (1 benign + 14 attack). The sample used in this project and how it was drawn are described in `DATASET_SETUP.md`; per-class counts for the corpus, the sample and each split are in `docs/results.md` §1.

## 2. Features (CICFlowMeter)

A flow is identified by the 5-tuple (src IP, src port, dst IP, dst port, protocol). The IPs and timestamps are **not** in the ML CSVs — only behavioural statistics, which is what makes the task generalisable:

| Group | Examples | Intuition |
|:--|:--|:--|
| Identity | `Destination Port` | which service was targeted (partial shortcut, see ablation) |
| Volume | `Total Fwd/Backward Packets`, `Total Length of Fwd/Bwd Packets`, `Flow Bytes/s`, `Flow Packets/s` | floods are big and fast; scans are tiny |
| Packet size | `Fwd/Bwd Packet Length Max/Min/Mean/Std`, `Packet Length Variance`, `Average Packet Size` | attack tools send uniform packets; browsers do not |
| Timing | `Flow IAT Mean/Std/Max/Min`, `Fwd/Bwd IAT *`, `Active/Idle *` | slowloris is *slow*; Hulk is bursty |
| TCP flags | `SYN/FIN/RST/PSH/ACK/URG Flag Count`, `Fwd PSH Flags` | half-open scans set SYN without ACK |
| TCP state | `Init_Win_bytes_forward/backward`, `min_seg_size_forward`, `act_data_pkt_fwd` | attack tools use distinctive default window sizes |
| Ratios | `Down/Up Ratio`, `Subflow *` | asymmetry of the conversation |

After cleaning (8 constant columns dropped) **70 features** remain.

## 3. Label

`Label` string, 15 values. Binary target for all experiments: `BENIGN → 0`, any attack → `1`. The original category is retained for the per-attack-type recall table and for stratifying the split.

## 4. Known issues in the raw CSVs (all handled in code)

* leading spaces in column names; `Fwd Header Length` duplicated as `Fwd Header Length.1`;
* `Infinity`/`NaN` in `Flow Bytes/s` and `Flow Packets/s` (zero-duration flows);
* mis-encoded en-dash in the three *Web Attack* labels;
* exact duplicate rows;
* a heavy class imbalance (80 % benign in the corpus; Heartbleed has 11 rows).

## 5. Limitations to state in the report

* A 2017 lab capture; modern traffic (QUIC, TLS 1.3, cloud) differs.
* Flow statistics only — payload-based attacks (SQL injection, XSS) look almost like normal web traffic at the flow level, which is why they are the hardest classes.
* Class-capped sampling changes the prior relative to the raw corpus (stated in the manifest).
