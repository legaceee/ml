# Reproducibility Guide

Everything in this repository — every number in the README, every table in `docs/results.md`, every figure in `docs/figures/` — is regenerated by the commands below. Nothing is typed in by hand.

## 0. Environment

```bash
python --version          # 3.11 or 3.12
pip install -r requirements.txt
```

Tested with Python 3.12, scikit-learn 1.7, XGBoost 3.4, Optuna 4.9, SHAP 0.52, imbalanced-learn 0.14 on an 8-core laptop with 12 GB RAM.

## 1. Get the data

The 55,720-row sample **is committed** (`ml/data/raw/cicids2017_sample.csv`, 19 MB, plus its manifest), so this step is only needed to rebuild it with different caps (one-off ~885 MB download):

```bash
python -m ml.data.build_dataset --download --build --benign-rows 40000 --attack-cap 1500
```

* `--download` fetches the 8 official CIC-IDS2017 *MachineLearningCSV* day-files (Monday … Friday) from a public mirror into `ml/data/raw/cicids2017_full/`.
* `--build` merges the 2,830,743 flows and writes the **class-capped stratified sample** to `ml/data/raw/cicids2017_sample.csv` plus a manifest (`cicids2017_sample_manifest.json`) recording the full-corpus and sample class counts.

Default caps: `--benign-rows 40000 --attack-cap 1500 --seed 42` → 55,720 rows. Change the caps to trade runtime for data size (an RBF-SVM's cost grows roughly quadratically with rows; see `docs/walkthrough.md` §2).

If you skip this step the loader falls back to a clearly-labelled **synthetic** fixture so the code can still be smoke-tested — but results on the fixture are not research results and every artifact is tagged `is_synthetic: true`.

## 2. Preprocess and split

```bash
python -m ml.preprocessing.pipeline
```

Produces `ml/data/splits/dataset_splits.joblib`, `ml/artifacts/preprocessors/preprocessor.joblib` and `ml/artifacts/metrics/dataset_summary.json`. Splits are stratified on the original attack category with seed 42 (70/15/15).

## 3. Run every experiment

```bash
python -m ml.training.run_all_experiments            # ~1 hour on 8 cores
python -m ml.training.run_all_experiments --quick    # ~4 minutes smoke test (small budgets, 6k train rows)
```

Writes:

| File | Content |
|:--|:--|
| `ml/artifacts/models/*.joblib` | 18 trained models (7 baselines, Optuna/Grid winners, 7 ensembles) |
| `ml/artifacts/metrics/master_comparison.json` | Every metric for every model + environment + budgets + timings |
| `ml/artifacts/metrics/cv_results.json` | 5-fold CV mean/std per baseline |
| `ml/artifacts/metrics/feature_selection_summary.json` | Scores, selected subsets and the measured benchmark |
| `ml/artifacts/metrics/pca_summary.json` | Explained-variance curve |
| `ml/artifacts/metrics/imbalance_study.json` | none / class_weight / under-sampling / SMOTE comparison |
| `ml/artifacts/metrics/optimization_study.json` | Grid vs Random vs Optuna histories and comparison |
| `ml/artifacts/metrics/per_class_recall.json` | Recall for each attack category, every model |
| `ml/artifacts/metrics/statistical_stability.json` | Bootstrap CIs + multi-seed retraining |
| `ml/artifacts/metrics/shap_global.json` | Global SHAP importances |
| `ml/artifacts/metrics/presets.json` | Real test-split flows used by the dashboard |
| `ml/artifacts/experiments/results.csv` | One row per experiment |
| `ml/artifacts/experiments/research_conclusions.json` | RQ1–RQ8 answers, generated from the numbers |

## 4. Render figures and documentation

```bash
python -m ml.training.generate_figures       # docs/figures/*.png
python -m ml.training.render_results_docs    # docs/results.md + README leaderboard block
python notebooks/generate_notebooks.py       # (re)creates the 7 notebooks
jupyter nbconvert --to notebook --execute --inplace notebooks/*.ipynb   # optional: run them with outputs
```

## 5. Tests

```bash
python -m pytest tests/ -q
```

* `tests/test_preprocessing.py`, `tests/test_models.py` — unit tests on synthetic data; run anywhere.
* `tests/test_model_predictions.py`, `tests/test_api.py` — integration tests against the trained artifacts; auto-skip if artifacts are absent.

## 6. Run the application

```bash
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload   # API + Swagger at /docs
cd frontend && npm install && npm run dev                           # dashboard at http://localhost:5173
```

## Determinism notes

* Global seed 42 everywhere (sampling, splits, CV folds, model seeds, Optuna's TPE sampler, bootstrap RNG).
* `n_jobs=-1` inside tree models does not change results; timings will differ between machines.
* XGBoost with `tree_method="hist"` is deterministic on CPU for a fixed seed.
* Multi-seed retraining (seeds 42/123/2024) is reported in `statistical_stability.json` so the reader can see how much the seed matters.
